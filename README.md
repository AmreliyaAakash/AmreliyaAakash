<a href="https://github.com/AmreliyaAakash/odoo-DealFlow360">
  <img width="100%" alt="DealFlow360 — B2B sales operations and quote-to-cash platform. Multi-tier discount governance, greedy set-cover allocation across warehouses, hybrid subscription proration, blended discount risk score, role-based access over an eleven-table schema. Built with Next.js, React, TypeScript, Supabase, PostgreSQL, Tailwind CSS and Clerk." src="https://raw.githubusercontent.com/AmreliyaAakash/AmreliyaAakash/main/assets/project-dealflow360.svg" />

**[DealFlow360](https://github.com/AmreliyaAakash/odoo-DealFlow360)** — a B2B quote-to-cash platform. Sales teams lose margin in the gap between quoting and invoicing, so this models that gap explicitly: tiered discount rules with approval thresholds, a risk score that tells an approver how exposed a deal is, set-cover allocation that fills an order from the fewest warehouses, and proration when a subscription changes mid-term. Built on an 11-table Postgres schema with a role-based access matrix.

`Next.js` `React` `TypeScript` `Supabase` `PostgreSQL` `Tailwind CSS` `Clerk` · no public demo — the repo includes setup instructions
